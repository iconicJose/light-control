# Light Control

Minimal Windows tray app for monitor brightness. Click the bulb in the tray, a dark
slider panel opens above it — one slider per display.

Handles both kinds of panel:

- **External monitors** over DDC/CI (`dxva2.dll`) — real hardware backlight, not a software dimmer.
- **Built-in laptop displays** over WMI (`WmiMonitorBrightnessMethods`).

Displays are matched to their friendly names through `QueryDisplayConfig`, which also
identifies the internal panel so it isn't listed twice.

## Design

- Single ~130 KB executable, no installer, no dependencies beyond the .NET Framework that ships with Windows.
- Idle cost is zero: no timers, no polling. Discovery runs on display-change events only.
- Brightness writes happen on a background thread with latest-value-wins, so dragging a
  slider stays smooth even though a DDC/CI write costs tens of milliseconds.
- The panel is a single owner-drawn window — no child controls.

## Build

```
build.cmd
```

Compiles with `csc.exe` from `%WINDIR%\Microsoft.NET\Framework64\v4.0.30319`, which is
present on every Windows install. Output: `build\LightControl.exe`. The bulb icon is
generated by `tools\make-icon.ps1` on first build.

## Use

- Left-click the tray icon to open or close the panel.
- Drag a slider, scroll the wheel over it, or use the arrow keys. `Esc` closes.
- Right-click the tray icon for **Start with Windows** and **Exit**.

## Notes

DDC/CI has to be enabled in the monitor's own OSD (some ship with it off). Monitors
connected through certain USB-C hubs or KVMs don't pass DDC/CI through and won't appear.
